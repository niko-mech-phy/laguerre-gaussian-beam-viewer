Ideal LG modes at the waist (z = 0): p = 0–4, |l| = 0–4

Each tile uses w₀ = λ and covers x/λ, y/λ ∈ [−3.5, 3.5]. Negative l has the same intensity but reversed phase winding. Phase is hidden where the field is nearly zero.

s: propagation distance; r, φ: transverse polar coordinates; k = 2π/λ. M² = 2p + |l| + 1.

Eₚ,ₗ = (Cₚ,ₗ / w)(√2 r / w)|l| Lₚ|l|(2r²/w²) exp(−r²/w²) exp[i(ks + lφ + kr²/2R − (2p+|l|+1)ψ)]
w = w₀√(1+(s/zᵣ)²), zᵣ = πw₀²/λ, ψ = atan(s/zᵣ), 1/R = s/(s²+zᵣ²), Cₚ,ₗ = √(2p!/[π(p+|l|)!])
