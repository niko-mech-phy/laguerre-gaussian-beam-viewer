# LG beam viewer (browser)

Open `index.html` in a modern browser; no installation, build, server, or network access is needed. Intensity is selected by default. Choose a local colormap (default viridis for intensity and RdBu_r for signed fields), adjust parameters, then select **Plot beams**. Six panels have labeled wavelength-normalized axes with equal physical scale on both axes (±3λ by ±3λ displays as a square), shared row normalization and a shared colorbar; **Save figure PNG** downloads the labeled six-panel plot. Gallery tiles show normalized waist modes and the gallery equations use native MathML. `colormaps.js` stores locally generated 256-entry, 8-bit RGB lookup tables sampled from Matplotlib 3.11.2 for viridis, RdBu_r, bwr, managua, vanimo, coolwarm, inferno, plasma, magma, and cividis. The browser uses the same discrete 256-bin mapping as Matplotlib; no external assets are loaded.

To deploy with GitHub Pages, commit this `web` folder to a repository, then either choose a Pages source whose root contains the HTML, CSS, and both JavaScript files or copy the contents of `web` to the repository's `/docs` folder and select **Deploy from a branch → /docs** in repository Settings → Pages. Do not configure a CDN or build step. The Python desktop app is unchanged.
