# LG beam viewer (browser)

Open `index.html` in a modern browser; no installation, build, server, or network access is needed. Adjust parameters and select **Plot beams**; **Save figure PNG** downloads the current six-panel plot. Gallery tiles show normalized waist modes.

To deploy with GitHub Pages, commit this `web` folder to a repository, then either choose a Pages source whose root contains these three application files or copy the contents of `web` to the repository's `/docs` folder and select **Deploy from a branch → /docs** in repository Settings → Pages. Do not configure a CDN or build step. The Python desktop app is unchanged.
